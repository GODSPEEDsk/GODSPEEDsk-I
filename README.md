# GODSPEEDsk-I

Este es mi primer repositorio, creado con el objetivo de distribuir **scripts escritos en Luau extendido**, es decir, utilizando funciones internas que no forman parte del entorno estándar de Roblox.

La mayoría de los scripts aquí publicados están específicamente diseñados para la experiencia **[Lucky Block Battlegrounds](https://www.roblox.com/es/games/662417684/LUCKY-BLOCKS-Battlegrounds)** de Roblox.

> **Importante:** Las funciones internas disponibles varían según el exploit utilizado.  
> Estos scripts están hechos para funcionar correctamente en el exploit _Delta_, por lo que podrían no funcionar o presentar inestabilidad en otros exploits que no sean _Delta_.

## ¿Cómo ejecutar los scripts de este repositorio?

Para ejecutar un script, usá el siguiente código en tu exploit:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/GODSPEEDsk/GODSPEEDsk-I/luaU/NombreDelCommit", true))()
```
Reemplazá _NombreDelCommit_ por el nombre exacto del archivo que quieras ejecutar.

Si el nombre tiene espacios, reemplazalos con %20.


Ejemplo: para ejecutar el script LuckyBlock giver, usá:
``` lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/GODSPEEDsk/GODSPEEDsk-I/luaU/LuckyBlock%20giver", true))()
```
Requisitos mínimos del exploit:

Soporte para loadstring

Soporte para HttpGet
